# Country Info App

A React application that displays country information using an API.

## 🚀 Live Demo

https://country-info-application-kappa.vercel.app/
## Features

- Search countries
- Filter by region
- Sort countries
- View country details
- Dynamic routing
- Loading state

## Technologies

- React
- JavaScript
- React Router
- Bootstrap
- REST API

## Project Structure

src/
├── components/
├── pages/
├── App.jsx
└── main.jsx

## How to Run

npm install
npm run dev
